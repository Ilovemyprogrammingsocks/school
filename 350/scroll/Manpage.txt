SCROLL				User Program

NAME
	scroll - automatically scroll through a text file and display contents

SYNOPSIS
	./scroll _file_

DESCRIPTION
	scroll is a program to gradually present the contents of a text file with some user control over the speed of the presentation.  This is a barebones program with only basic error handling and several cosmetic issues, which verge into functional issues due to the cosmetic nature of the program.

COMMANDS
	Commands are entered via keypress during runtime, and are recieved unbuffered, so take care not to mispress.  unimplemented characters entered are ignored

	q
		quit: cleanly exits the program resetting the echo and canonical recording terminal settings
	
	return
		pause/resume: stops scrolling indefinitely until another return signal is processed.  resuming from a stand still will set scroll speed to default

	spacebar
		skip: skips forward one page and pauses, meant to emulate MORE(1) style scrolling.  can resume with a return.

	f
		faster: speeds up scroll speed by 20% current speed, has no effect if paused
	
	s
		slower: slows scroll speed by 20% current speed, has no effect if paused
	

ENVIRONMENT
	this program uses and overwrites the following environment variables

	ITIMER_REAL
		used by setitimer() and alarm

	terminal ECHO and ICANON flag bits
